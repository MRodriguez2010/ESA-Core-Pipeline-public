# Archived ratings snapshot

These are the aggregate numerical fields from the April 1, 2026 export. Each file has 40 source rows. Company labels, comparison roles, review counts, category ratings, percentages, zeroes and missing values follow the source. Some original company labels are URLs; they are preserved as supplied. Source-page URLs identify the reviewed listing; the underlying websites can change. Different platforms and measures should be compared separately.

The recommendation column contains the original fractional share. Percentages in the distribution file use the source units. Blank cells mean the archive did not supply a value. This export omits the internal project ID, free-text review excerpts and private Office metadata.
